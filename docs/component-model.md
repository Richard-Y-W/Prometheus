# Component model

Published component revisions are immutable and retain lineage. Every meaningful value uses the evidence-backed value contract in `schemas/component-package.schema.json`. Certification tier describes evidence (`provisional`, `geometry_verified`, `behavior_verified`, `physically_validated`, `system_validated`) and is not a general safety claim.

Ports and frames are explicit, typed, and coordinate-system aware. Compatibility is a deterministic typed rule result. Manufacturer part numbers preserve original spelling; normalized aliases are separate.
