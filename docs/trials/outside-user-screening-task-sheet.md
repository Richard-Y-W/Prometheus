# Prometheus project-folder exercise

You will use a supplied Windows application and project folder. Please work on
your own and say what you are thinking as you go. This is a test of the
software, not of you. If something is unclear or does not work, say so rather
than trying to give a “correct” answer.

1. Double-click `Launch-Prometheus.cmd`.
2. Tell the observer when you think Prometheus has finished looking through
   the supplied project folder and whether all of its files appear to be
   accounted for.
3. Find one 3D model that Prometheus says it can load, and open it.
4. In your own words, explain why Prometheus did or did not automatically
   choose a complete rover assembly.
5. In your own words, explain the difference between a file marked
   `unsupported` and one marked `not evaluated`.
6. State whether Prometheus has established that this rover project works, and
   explain your answer.
7. Tell the observer when you are finished.

You may stop at any time. Please do not open the observation form or integrity
files during the exercise.
